# Monarchy Docs

The Queen is dead, long live the Queen.

Monarchy gives you one conversation with the Queen for requests, status, decisions,
and results. The royalty handle delegation and coordination behind the scenes.
Start here to set up that conversation and understand what comes back to you.

- [Set up the royalty](quickstart.md): set up the home and try one bounded task.
- [Meet the royalty](how-it-works.md): your conversation with the Queen and the work behind it.
- [Pass the crown](succession.md): transfer responsibility and recover after interruption.
- [Use Conductor](conductor.md): connect the workflow to visible agent sessions.
- [Run the royalty](runtime.md): register assignments, handle reports, and deliver scoped answers.
- [Choose a skill](skills.md): twelve core workflows and checked 00 agent packages.
- [Watch the work](observer.md): validate a task register and read live status.
- [Configure the royalty](configuration.md): validate preferences, confirm founding choices and pin exact sources.
- [Delegate within a grant](delegation.md): confirm category scope, retain actual answer provenance and revoke authority.
- [Keep checks and digests current](cadence.md): use durable check receipts, bounded waits and an explicit builder census.
- [Plan capability parity](planning/opinionated-defaults.md): phased roadmap with activation and migration kept separate.
- [Build ahead, keep the owner in charge](planning/continuous-backlog.md): design input for grant-bound continuous building and sign-off; not an installed background service.
- [Know the limits](limits.md): what this version implements and what remains manual.

The [record layer](runtime-records.md) keeps the royalty's history. The
[Conductor adapter](conductor-transport.md) checks native bindings and reconciles
uncertain delivery. The [First Mate adoption plan](planning/firstmate-adoption.md)
explains which contracts were ported and what the bundled source is used for.

Agent instructions live in [roles](../roles/queen.md). Reusable records live in
[templates](../templates/brief.md). [Decisions](decisions/README.md) explain the
standing choices behind the project.
