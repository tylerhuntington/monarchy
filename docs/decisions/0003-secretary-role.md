# 0003: Secretary Role

Status: Accepted
Pacific date: 2026-11-15

## Decision

The owner chose **Secretary** as the coordination role's name and requested
consistent use throughout Monarchy's documentation and code. Use `secretary` in
filenames and technical references, including `roles/secretary.md`.

The Secretary keeps task records, coordinates assignments and reviews, and
brings decisions to the Queen. The user continues to work through the Queen's
conversation.

## What stays unchanged

This is a naming change. The role's responsibilities, existing authority limits,
supervised handoff requirements, and runtime behavior remain unchanged. It does
not rename or migrate the separate PISCES installation.

## Consequences

Current instructions, guides, templates, and earlier decision text use the same
name. Git history remains intact.
